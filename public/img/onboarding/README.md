# Entry-flow food imagery

Created on 2026-10-16 with the built-in image_gen tool. These are generated editorial illustrations, not photographs of users' logged meals. No text or interface is baked into them. Originals were converted to WebP quality 83, retaining their composition. The produce image is 1024px wide; cuisine images are 1536px wide. Onboarding backgrounds are decorative and are not dietary recommendations.
